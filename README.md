# Simulación — Yahtzee con Montecarlo

Entrega de la simulación del Yahtzee clásico para dos jugadores. El programa repite miles de partidas y muestra cómo el puntaje medio se estabiliza (Ley de los Grandes Números).

## Guía del profesor

Estos archivos se usaron como punto de partida y no se reescribieron:

- `simulacion_01.ipynb` — bloqueo de dados por Montecarlo (32 máscaras).
- `Laboratorio Yahtzee.jsx` — tablero para dos personas.
- `Laboratorio Yahtzee Montecarlo.html` — enunciado del laboratorio.

## Programa

Todo el desarrollo está en `yahtzee_montecarlo/`. Ahí están el código, las pruebas, las gráficas y el borrador del informe (`docs/informe_tecnico.md`).

En Windows, el juego se abre con doble clic en `yahtzee_montecarlo/Ejecutar Yahtzee.bat`. La explicación de las fases USA, MODIFICA y CREA está en el `README.md` de esa carpeta.
